# Laptop keyboard flight bindings (preview seed).
# Engine-default actions whose base key exists only on a numeric keypad
# (Src/Orbiter/Keymap.cpp lkeyspec), restated with physically laptop-reachable
# base keys. Syntax is the engine keymap.cfg vocabulary (Keymap::ScanStr).
# First match wins in Keymap::Read, so these lines must precede the generated
# engine defaults in keymap.cfg. Deliberate conflicts, matching stock Orbiter
# layering (immediate handlers consume keys only in their own modes):
#  - Ctrl+1/2 replace Ctrl+keypad +/-; main-row 1/2 have no default binding.
#  - 1/2 additionally bank; arrows additionally panel-shift (internal only);
#    H/J/K/L additionally HUDMode; none collide in external flight view.
